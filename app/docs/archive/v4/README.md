# 饥荒单机版存档备份工具

按「世界 / 槽位」粒度备份与回滚《饥荒》单机版（Don't Starve, Steam AppID 219740）存档的图形化工具。

## 为什么会有这个项目

- 饥荒单机版**一个世界就是一个存档**，但市面上的通用存档管理器（Game Save Manager 等）倾向于一次性备份全部游戏存档，容易出错
- GitHub 上现成的饥荒专属备份工具（如 `DoNotStarveBackup`、`dont-starve-backup`）多为个人练手项目，无发布包、年久失修，不适合直接使用
- 因此自研一个轻量、单文件、中文界面的专用工具

```
│ 存档目录  [d:\...\219740\remote         ▾] [浏览] [刷新]     │

│ 世界  4 个         │  威尔逊 · 海难          [备份此世界]     │
│                    │  274 天 · 3 份备份 · 4.2 MB             │
│ ●威尔逊·海难·274天 │  ● 10-27 09:50  274天  1.4MB  手动 恢复 │
│  WX-78·哈姆雷特…   │  ○ 10-27 09:50  274天  1.4MB  自动 恢复 │
│  威尔逊·冒险·8天   │                                         │
│  5 份备份 · 10.0MB │                                         │
└────────────────────┴─────────────────────────────────────────┘
```

窗口是无边框的（`decorated=False`），标题栏、最小化、最大化、关闭都是自己画的。
图标用 Windows 自带的 **Segoe Fluent Icons**，不装字体、不打包字体文件。

配色规则只有两条：灰阶永远中性（不带黄），强调色只出现在「当前选中的世界」和「主动作按钮」。
四套强调色只换三个值，灰阶不动，所以换色不会破坏整体气质。

## 目录结构

```
饥荒单机版存档备份\
├─ 饥荒存档备份工具.exe       主程序（单文件，双击即用，可随意拷贝）
├─ dst_saver_config.json      配置文件（exe 同级，软件自管）
├─ backups\                    备份存放目录（exe 同级）
│  └─ slot_<槽位ID>\<时间戳>[_auto|_pre]\   一个快照 = saveindex + 该槽位全部世界文件
├─ src\
│  ├─ main.py                 入口：视口、窗口外壳、主循环
│  ├─ theme.py                配色令牌、字体、主题对象
│  ├─ widgets.py              通用小控件 + Win32 窗口操作（拖动/最大化/圆角）
│  ├─ pages.py                界面骨架：标题栏 / 工具条 / 世界栏 / 设置页 / 弹窗
│  ├─ app.py                  全局状态、业务回调、自动备份巡检
│  ├─ backup_core.py          备份/恢复/清理/统计
│  ├─ klei_format.py          存档格式解析
│  └─ preview.py              开发用：指定主题和页面启动，方便截图
├─ docs\                      技术记忆与开发记录
├─ build.bat                  重新打包脚本
└─ README.md
```

**分层约定**：`klei_format` 纯解析 → `backup_core` 纯业务 → `theme/widgets/pages` 界面 → `app` 状态与动作 → `main` 组装。
`pages.py` 单向依赖 `app.py`，`app.py` 不反向 import（用 `app.RENDER` 注册表回调），避免循环依赖。

## 使用方式

1. 双击 `饥荒存档备份工具.exe`
2. 左侧列出所有非空世界，格式 `角色 · 模式 · 天数`，前面的 ● 表示这个世界已有备份
3. 选中世界 → 右侧显示备份时间轴 → 点右上角「备份此世界」拍快照
4. 死亡后：在时间轴里点对应备份的「恢复」→ 确认 → 重进游戏回到那一刻
5. 「设置」里可调：主题（跟随系统 / 暗色 / 亮色）、**强调色（火橙 / 靛蓝 / 苔绿 / 紫檀）**、
   字号（小 / 标准 / 大）、备份目录、手动与自动备份各自的保留份数、关闭按钮行为

**⚠️ 恢复前务必完全退出游戏**，工具会检测 `dontstarve.exe`，检测到运行会拒绝恢复。

- 备份只往备份目录写文件，**不碰原存档**
- **恢复前会自动给当前状态拍一份「恢复前」快照**，恢复错了还能退回来
- 唯一有风险的写操作是恢复时的覆盖，且有二次确认

## 自动备份

- 盯着每个世界文件的改动（不是 `saveindex` —— 它是所有世界共用的，分不出是哪个世界动了）
- 文件连续两轮巡检都没有新变化才认为写完了，避免拷到写了一半的存档
- 同一世界 60 秒内只备一次
- 自动备份与手动备份**分开计数**，自动备份不会把你精心留的「打 BOSS 前」挤掉
- 工具条上的「自动备份 · 开/关」可随时切换

## 存档位置（自动扫描）

- Steam 版：`Steam\userdata\<SteamID>\219740\remote`
- 独立版 / 部分 Steam 版：`文档\Klei\DoNotStarve\save`
- 本机实际路径：`D:\Software\Steam\userdata\1222722443\219740\remote`

## 从源码运行

```bat
cd src
python main.py
```

依赖：`dearpygui>=2.3`、`pystray`、`pillow`（均为 pip 安装）

> 本机只有 WorkBuddy 内置的 Python 3.13（无 tkinter），且无 .NET SDK，因此 GUI 方案选定 Dear PyGui。

## 构建说明

见 `build.bat`，本质命令：

```bat
cd src
python -m PyInstaller --onefile --noconsole --clean --name "饥荒存档备份工具" main.py
```

打包产物在 `src\dist\`，脚本会自动拷到项目根目录。
