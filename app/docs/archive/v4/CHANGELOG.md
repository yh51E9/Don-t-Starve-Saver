# 更新日志

## v4.1 (2026-10-27)

### 图标
- 接入 Windows 自带的 **Segoe Fluent Icons**（`SegoeIcons.ttf`，Win10 退回 `segmdl2.ttf`）。
  不用装 nerd font、不用带字体文件、不用联网，系统一定有
- 窗口按钮换成真实字形（最小化 / 最大化 / 关闭），工具条的「浏览 / 刷新」改成图标按钮，
  标题栏左侧加了存档库图标

### 配色
- **暗色整体抬亮**：从 `#101114`（接近纯黑）改成 `#1B1D21`，四级层次
  `bg #1B1D21 → rail #212429 → card #272B31 → raise #31353C`，不再是"一块黑洞"
- **四套强调色**：火橙 / 靛蓝 / 苔绿 / 紫檀，设置页可切。灰阶不动，只换"灯光的颜色"
- **按钮文字改成反色**：暗色主题的强调色偏亮 → 配近黑字；亮色主题的强调色偏深 → 配近白字。
  原来白字压橙底只有 2.7:1，现在四套都在 4.5:1 以上

### 字号体系
- 三个尺寸定死：display `base+4`（20）/ body `base`（16）/ meta `base-3`（13），比例约 1.25
- 区块标题跟正文同尺寸，只换字体家族（等线 Bold），靠家族和字重分层，不再"大一号"

### 窗口按钮
- 三个按钮做成 48×48 正方形，和标题栏等高、彼此紧贴、贴齐右上角，无圆角——和 Windows 原生一致
- 关闭按钮悬停是系统红 `#C42B1C`

### 修复
- 标题栏元素垂直不居中（DPG 单元格顶端对齐，改成"每一项单独算 (条高-字号)/2"）
- 窗口按钮被挤出右边（三个按钮之间还有 ItemSpacing，标题栏的 ItemSpacing 归零后才贴边）
- 设置页加了一行后又超出一屏（存储并进备份区块，表单项间距收到 4）

## v4.0 (2026-10-27)

界面与代码结构的一次整体重做，同时补上三项一直缺的功能。

### 界面
- **无边框窗口**：`decorated=False` 自绘标题栏，最小化/最大化/关闭全部自己实现；
  启动时窗口位置在创建视口时就算好，不再有"先闪一下再跳过来"的白闪
- **配色改为中性基底 + 单一强调色**：原来侧栏棕、标题橙、按钮橙三种暖色互相打架，
  整片暖色让人误以为界面发黄；现在灰阶全部中性，火橙只出现在「当前选中的世界」和「主动作」
- **字体分两个家族**：标题用等线 Bold、正文用微软雅黑，靠字体家族和字重拉层级
- **布局重排**：去掉 200px 导航侧栏（只有两个页签不值这个钱），导航移入标题栏；
  世界栏 320px 常驻左侧，备份历史占满右侧
- **备份历史改为时间轴**：左边是时间/天数，右边是体积/来源/操作，中间留白分组；
  最新一份的节点是实心橙色
- **删除"选中备份"这层状态**：恢复/删除改成行内按钮，原来的三按钮操作栏随之消失
- 主动作固定右上角（备份此世界 / 保存设置），内容再长也不会被挤出视口
- 字号档位从 8 档收敛到 3 档（小 14 / 标准 16 / 大 18），启动更快

### 新功能
- **自动备份**：巡检世界文件的改动，连续两轮稳定才备；同一世界 60 秒冷却；
  与手动备份分开计数，不会把手动留的挤掉
- **恢复前自动快照**：覆盖前先给当前状态拍一份 `_pre` 备份，恢复错了能退回来
- **空间统计**：世界栏底部显示总份数与占用，设置页有清理入口
- **备份元数据**：解析每份备份里的 `saveindex`，时间轴显示"当时是多少天、什么角色、什么模式"

### 代码结构
- `main_gui.py`（906 行）拆成 5 个模块：`main` / `theme` / `widgets` / `pages` / `app`
- `pages.py` 单向依赖 `app.py`，`app.py` 通过 `RENDER` 注册表回调，避免循环依赖
- 主题、字号变化时整界面重建（`rebuild_all`），不做增量重绑，少一类状态同步 bug

### 修复
- 内容区出现莫名滚动条（负高度没扣掉上面两块占用的高度，状态栏被挤出窗口 8px）
- 所有文字都贴在容器边缘（`border=False` 的 child window 会忽略主题里的 WindowPadding）
- 世界列表文字居中（button 居中，改用 selectable）
- 世界列表整块不显示（selectable 不吃 `width=-1`，宽度算成 9px）
- 窗口标题乱码且无法修正（句柄抓到输入法的隐藏窗口；DPG 在头几帧会覆盖标题）
- 亮色主题下输入框/下拉框是深色块（基础控件色没写进全局主题）
