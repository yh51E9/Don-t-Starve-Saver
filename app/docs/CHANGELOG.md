# 更新日志

> 两份更新说明分工：`app/backend/ds_saver/assets/CHANGELOG.md` 是设置页「关于」渲染的用户版（简洁易懂）；本文件是仓库开发日志（详细）。发版时两份都要更新。

## 1.0.1 (2026-11-08)

**撤销体系与新建存档修复**：危险操作可一键撤销，新建存档不再漏备份。

### 新增
- **撤销体系**（`core/undo.py`）：删备份 / 删存档 / 恢复等危险操作记入撤销日志（50 条），`Ctrl+Z` 全局撤销；删除的备份进 `backups/_trash` 回收站保留 7 天可找回；左栏右键「撤销刚才的操作」「恢复已删除的存档槽位」（孤儿快照 = save_id 不匹配任何当前世界）
- **快捷键面板**：设置页快捷键一览（可改键 / 恢复默认）；卡片式布局自动换行，超 8 条自动出现筛选框
- **恢复放行**：`restore` 接口新增 `confirmed_idle`——游戏开着但没在玩这个存档时，弹窗勾选「我确认游戏没有在玩这个存档」后放行；未勾选仍拦截（含提交后游戏才启动的任务层复检）
- **「上一个世界」警示**：备份的 save_id 与当前世界不一致时详情弹窗给黄色警示，防恢复错档

### 修复
- 游戏内新建的存档不出现在列表：`list_worlds` 刷新前重读 saveindex（此前只回缓存）
- **自动备份漏打新建存档**：新档「文件先落盘、槽位后登记」，巡检旧逻辑「首见即基线」吞掉建档写盘 → 新文件写稳两轮补打快照；启动首轮分流（已有备份只记基线、零备份补保底）；任务失败补 warning 日志不再静默
- 删除选中世界后界面卡住：`refreshData` 不再被 `selectWorld` 失败掀翻（解耦 + try/catch）

### 调整
- 默认 `close_action` 由 `tray` 改为 `ask`（关闭时弹窗确认）

## 1.0.0 (2026-10-31)

**首个正式版本**：饥荒单机版（Don't Starve）存档的备份、恢复与图片管理一站式工具。下接 v5.x 为发布前的开发版本记录。

### 主要功能
- **自动备份**：游戏保存 / 游戏关闭 / 定时巡检三种触发方式，保留份数与天数可调，`_pre` 保护快照永不淘汰
- **手动备份与恢复**：一键备份当前存档；恢复到任意备份，恢复前自动拍「恢复前」后悔药
- **导入导出**：备份打包 zip 带走（含多份），zip / 7z / rar 可导入为备份或直接写入存档
- **备份表格**：搜索高亮、按时间 / 天数 / 差值 / 体积排序、来源与兼容性筛选、备注、批量删除
- **存档管理**：多槽位世界列表、存档详情、Mods 一览、删除存档（回收站 + 账本摘除）
- **头像与图片库**：官方 / 用户上传 / Mod 角色头像分层管理，Mod 图标统一图片库
- **外观**：三套主题 × 明暗双模式 × 五档字号（14–22 自定义），点击即预览
- **安全机制**：saveindex 槽位级恢复（不动其他槽）、删除进回收站、便携式目录（整目录拷走即迁移）

### 命名规范（dst → ds）
- **命名空间前缀更名**：`dst` → `ds`，纠正单机版 DS 与联机版 DST 的缩写混淆。涉及 CSS 变量（`--ds-*`）/ 类名（`ds-*`）/ `data-ds-preset`、存储与通信键（`ds:*`，含 localStorage/BroadcastChannel/CustomEvent）、后端包 `dst_saver` → `ds_saver`、配置文件 `dst_saver_config.json` → `ds_saver_config.json`、产品名 `dst-saver` → `ds-saver`、标识符 `DstError`/`DstEvent` → `DsError`/`DsEvent`
- **数据迁移**：localStorage 旧键 `dst:*` 与配置旧文件名自动迁移（新值优先、不丢设置）；互斥体双占位（新旧名），升级瞬间新旧版本互斥
- 指联机版游戏本身的字面量（`Don't Starve Together`、`dont_starve`、`DST-Saver-Backups` 等）保持不变

## v5.2.0 (2026-10-27)

### 数据与安全（P1）
- **saveindex 外科手术式恢复**：恢复只替换目标槽位条目（`slot_entry` + `splice_slot`），不再整份覆盖账本——恢复槽 1 不再影响槽 2；账本损坏时兜底整体覆盖。真实存档副本演练通过
- 修复 `parse_lua_table` 的 bracket-key 静默损坏（`["str:1"]` 首字符被吃），parse→serialize→encode→decode→parse 全等门禁
- **删除存档**：文件进 `backups/_trash` 回收站 + saveindex 摘除条目（`drop_slot`），故障注入下完整回滚；右键菜单新增删除所有备份 / 删除存档（输入槽位号三重确认）
- **扫描候选确认**：不要求 saveindex 存在，报告 Steam 账号名（PersonaName）/ 世界数 / 修改时间；首次无存档目录自动弹确认；`save\` 与父目录都作为候选（新老布局通吃）
- **自动备份策略**：变化时 / 固定间隔 / 两者；min_gap 抑制互相挤兑；开机不乱打（基线起点）；可选"仅游戏运行时"
- **按天数保留**：保守交集语义（超龄 **且** 超份数才删），`_pre` 后悔药永不参与天数淘汰
- **游戏运行检测加固**：`dontstarve*` 前缀匹配（不再漏 `dontstarve_steam.exe`）、Win32 原生进程快照（tasklist 兜底）、恢复/删除执行前 force 复检

### 界面与布局（P2）
- **三栏可拖拽**：世界栏 240–460、详情栏 200–340，localStorage 持久化
- **设置独立窗口**：第二个 pywebview 窗口（980×720），关闭闸门拦截未保存修改，双窗标题栏同步染色
- **主题点击即预览**：设置窗换肤实时可见，主窗经 storage 事件跟随，保存才落盘、放弃自动回滚
- **头像库**：内置 / DLC / Mod 分组统计 + 缺素材名单 + 缓存体积，重新扫描 / 重建缓存按钮
- **存档详情折叠面板**：建图日期、最后游玩、总大小、DLC、Mods（modinfo.lua 解析，失败降级 id）、文件清单
- **时间轴按周目分组**：按 save_id 分"第 N 周目 · 建图日期"，同槽重开世界的备份不再混在一起
- 头部闪电图标换成「自动备份」文字 + Switch

### 修复
- **存储全部收进项目目录**：头像缓存 / mod 名称缓存 / 日志 / WebView2 存储从 `%LOCALAPPDATA%\dst-saver` 迁到 `app\data\`，便携式布局——整个 app\ 目录拷走即完整迁移（旧 LOCALAPPDATA 数据不再使用，可手动删除）
- Mantine Collapse 属性名（`expanded`）、ActionIcon light 变体、根字号亚像素发糊（root 16px + 整数 token）

## v5.0.0 (2026-10-27)

整体重写。界面从 Dear PyGui 换成 **pywebview + React 19 + Mantine 9**，
业务层（存档解析、备份布局、配置键）保持兼容。

### 界面

- 三栏骨架：280px 世界卡片 / 中间备份时间轴 / 220px 会话信息
- 世界卡片带角色徽记、模式图标、天数、备份数与上次备份时间
- 时间轴按日期分组，显示「时间 / 天数 / 与当前差值 / 来源 / 体积」，悬停出现恢复、定位、删除
- 恢复确认显示「当前 274 天 → 备份 271 天，会退回 3 天」，并提示会先拍 `_pre` 快照
- Ctrl+K 命令面板（切世界、备份、清理、设置、打开备份目录），Ctrl+B 备份
- 主题三套可切：夜航（冷灰石墨 + 月光青）、野外手账（暖炭纸白 + 发丝线）、暗铜机械（墨绿黑 + 黄铜）
- 只用 Windows 系统字体；Tabler 图标贯穿世界、来源、操作、状态与空态
- 系统原生标题栏，DWM 染成界面底色（Win11 22H2+ 连标题文字和边框一起染）

### 修掉的 10 个旧问题

1. `delete_backup` 不校验路径 → 所有接口只收不透明 id，`realpath` 白名单挡 `..\..`
2. 恢复先复制后校验 saveindex → 改为**先校验后复制**，失败时存档一个字节都不动
3. 配置非原子写、损坏即静默清空 → tmp + `os.replace`，坏文件备份成 `.bak-时间戳`
4. 默认值散落各处 → `config.DEFAULTS` 单一来源 + 字段校验
5. `_meta_cache` 无锁且永不淘汰 → 直接去掉（单份解析 1.6ms）
6. 同秒多份备份排序不稳定 → `(stamp, dir_name)` 双键倒序
7. `is_game_running` 阻塞 10 秒 → 3 秒缓存
8. `keep=0` 语义反直觉 → 改为「清空该组」，设置面板最小值锁 1
9. 已删除世界的备份永远清不掉 → `cleanup` 扫全部 `slot_*`，返回孤儿清单
10. 源码与 exe 的备份/配置目录不一致 → `paths.app_dir()` 统一出口

顺带修掉：`busy` 时自动备份队列条目被丢弃（改成排队）、巡检 `seen` 不清理已删文件、
恢复 `_pre` 用错世界（现在按备份所属槽位拍）。

### 新增

- 备份/恢复进度反馈（文件数 + 字节数，100ms 节流）
- 任务结果通过事件回传，失败有错误码与中文提示
- 设置页可直接切换三套主题、明暗、字号，改完即时生效
- 存储占用与「清理超限备份」入口

### 说明

- `close_action="tray"` 从「最小化到任务栏」修正为「隐藏到托盘」（配置值不变）
- 数据层 42 条 pytest；主题对比度 90 项门禁（predev / prebuild 自动跑）
